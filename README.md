# Quaqqer computercraft

This is a repo containing code for my computer craft adventures.

## Goals

- Path finding - find path from A to B. Since the turtle can't know its
  environment it needs to keep track of blocks it has seen. This should be a
  method of the bot, ex. `bot:goto(x, y, z)`.
- Digging a hole - Dig a square hole. You can make it easier or harder for
  yourself. We can just go to the top right of the border. Dig out zig zag, the
  we go to the top right again.
